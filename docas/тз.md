**Что должно быть готово:**

- Тип ссылки: исходный URL, короткий код и дата создания.
- Тип сервера, который хранит ссылки в `map` (код → ссылка). Пока данные живут в памяти и пропадают при перезапуске. БД подключим позже.
- Две ручки: создать ссылку и перейти по коду.
- Валидация входящего URL.
- Генерация уникального короткого кода.
- Понятные ошибки с правильными статусами (400, 404) и без паник.
- `main`, который собирает всё вместе и запускает сервер.

**Поправки:**

1. **Не «сервис».** Отдельный сервисный слой в Go — привычка из .NET. Чтение и запись ссылок сейчас пусть будут методами сервера. Отдельное хранилище выделим, когда появятся mutex и тесты.
2. **Публичность пока ни на что не влияет.** Всё лежит в одном пакете `main`, а заглавная буква важна только для доступа из другого пакета. Сейчас заглавные нужны только полям, которые уходят в JSON.
